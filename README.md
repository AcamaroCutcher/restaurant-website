# 🌮 Xochitl Rojo - Restaurant Website

A beautiful, modern, and responsive website for Xochitl Rojo, a family-owned Mexican restaurant in Ecuador.

## ✨ Features

- **Modern & Aesthetic Design**: Clean, crisp interface with beautiful gradients and animations
- **Fully Responsive**: Looks perfect on all devices (desktop, tablet, mobile)
- **Smooth Animations**: Engaging scroll animations and transitions
- **Interactive Elements**: Hover effects, smooth scrolling, and dynamic content
- **Optimized Performance**: Fast loading and smooth user experience

## 📁 File Structure

```
restaurant-website/
├── index.html      # Main HTML structure
├── styles.css      # Complete styling and responsive design
├── script.js       # Interactive features and animations
└── README.md       # This file
```

## 🎨 Sections

1. **Hero Section**: Eye-catching introduction with restaurant name and tagline
2. **About Section**: Story of the family-owned restaurant with key features
3. **Menu Section**: Beautiful food gallery showcasing signature dishes
4. **Family Section**: Introduction to the team behind the restaurant
5. **Contact Section**: Location, hours, and contact information

## 🚀 How to Use

Simply open `index.html` in any modern web browser. No build process required!

### Option 1: Direct File
```bash
# Open the file directly
open index.html
```

### Option 2: Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have npx)
npx serve

# Then visit: http://localhost:8000
```

## 🎨 Customization Guide

### Update Content

1. **Restaurant Name**: Search for "Xochitl Rojo" in `index.html` and replace
2. **Colors**: Modify CSS variables in `styles.css` (lines 2-12)
3. **Add Real Images**: Replace the placeholder divs with actual `<img>` tags

### Add Real Food Images

Replace the placeholder sections like this:

```html
<!-- Current placeholder -->
<div class="food-image-placeholder">...</div>

<!-- Replace with real image -->
<img src="path/to/your/image.jpg" alt="Tacos al Pastor">
```

### Update Contact Information

Edit the contact section in `index.html` with your actual:
- Address
- Phone number
- Email
- Operating hours
